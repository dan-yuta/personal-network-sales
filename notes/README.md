# notes/ — 雑記・議事録・振り返り

実装中に生まれる「設計ではない記録」を置く場所です。
ここは構造を強制せず、思考の流れを残すためのフォルダです。

## 想定する中身

- 実装中に詰まったポイントとその解決メモ
- 講師との打ち合わせ議事録
- 自分でのKPT (Keep / Problem / Try) 振り返り
- 設計に昇格させる前の発想メモ
- Notion API の挙動で発見したこと
- shadcn/ui の使い方で覚えたこと

## ファイル命名

- 日付プレフィックスを推奨: `2026-05-12_optimistic_update_pitfall.md`
- 議事録は: `2026-MM-DD_meeting_<相手>.md`
- KPT は: `2026-MM-DD_kpt.md`

## docs/ との違い

| 項目 | docs/ | notes/ |
|------|-------|--------|
| 性質 | 仕様の正本 | 個人メモ |
| 文体 | ビジネス資料 | 自由 |
| 更新タイミング | 設計変更時 | いつでも |
| 提出物に含まれるか | はい | いいえ |
