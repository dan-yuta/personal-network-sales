# assets/ — 画像・図表素材

UI のスクリーンショット、設計図の画像版、参考画像などを置く場所です。

## 想定する中身

- 完成画面のスクリーンショット
- ペイン構造の図 (PNG/SVG)
- Notion DB のキャプチャ
- 名刺サンプル等のダミー画像
- 提出用スクリーンショット集の元画像

## ファイル名の規約

- 連番＋内容で命名: `01_workspace_screenshot.png`、`02_pane3_dashboard.png`
- 日本語ファイル名は避ける（OneDrive と Git の相性問題回避）
- 大きいファイル (1MB超) は `submission/` か外部ストレージへ

## 注意

- **個人情報を含む実データのキャプチャは置かない**（顧客名、メールアドレス、電話番号 等）
- どうしても実データが必要な場合はマスキング済み版のみ
