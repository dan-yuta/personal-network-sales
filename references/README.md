# references/ — 外部資料・参考リンク集

このプロジェクトで参照した外部資料・URL・PDFなどを置く場所です。
リンクが切れる前にローカルに保存しておきたい資料もここへ。

## 想定する中身

- workspace-ui-kit リポジトリの README コピー
- shadcn/ui ドキュメントの抜粋
- Notion API 公式ドキュメントの抜粋
- AI-Driven School 課題ガイド
- パートナーシップ関連資料
- 参考にした他社営業ツールのスクリーンショット

## 想定するファイル

- `links.md` — URL一覧をMarkdownで管理
- `notion_api_quickref.md` — Notion API のよく使うエンドポイント一覧
- `*.pdf` — オリジナル資料

## links.md の書き方例

```markdown
## Notion API
- [公式 Reference](https://developers.notion.com/reference/)
- [Database Query](https://developers.notion.com/reference/post-database-query)

## shadcn/ui
- [Components](https://ui.shadcn.com/docs/components)

## workspace-ui-kit
- [リポジトリ](https://git.ai-driven-school-portal.com/ADS/workspace-ui-kit)
```

## 注意

- 著作権のある資料を再配布しない
- 個人で参照する目的での保存に限る
