# 00. ツール起動・確認方法

人脈営業ツール（`tool/` 配下の Next.js プロジェクト）をローカルで起動して動作確認するための手順書。
**このファイルだけ読めば、初めて触る人でも起動できる状態**を目指しています。

---

## 0. 前提条件

| 項目 | 要件 | 確認コマンド |
|------|------|------------|
| Node.js | v18 以上（推奨: v24.x） | `node --version` |
| npm | v10 以上 | `npm --version` |
| Git | 任意のバージョン | `git --version` |
| OS | Windows 11 / macOS / Linux | - |

Node.js が未インストールの場合は https://nodejs.org/ から LTS 版をダウンロードしてください。

## 2. 依存パッケージのインストール

`tool/` 配下に Next.js プロジェクトの依存が定義されているため、`tool/` で `npm install` を実行します。

```powershell
cd tool
npm install
```

**所要時間**: 2〜3分（771 パッケージ）

成功時の出力例:

```
added 771 packages, and audited 772 packages in 2m
```

---

## 3. 開発サーバーの起動

### 3-A. デフォルトポート (3000) で起動

```powershell
npm run dev
```

### 3-B. ポート 3001 で起動（テンプレート側 3000 と共存する場合）

```powershell
$env:PORT=3001
npm run dev
```

成功時の出力例:

```
▲ Next.js 16.2.6 (Turbopack)
- Local:         http://localhost:3001
- Network:       http://192.168.x.x:3001
✓ Ready in 1.7s
```

## 6. 開発サーバーの停止

PowerShell で起動した dev サーバーを停止する方法:

| 方法 | 操作 |
|------|------|
| フォアグラウンドで起動した場合 | ターミナルで `Ctrl + C` |
| バックグラウンドで起動した場合 | プロセスを kill: `Get-NetTCPConnection -LocalPort 3001 \| Select-Object -ExpandProperty OwningProcess \| ForEach-Object { Stop-Process -Id $_ -Force }` |

## 7. トラブルシューティング

### Q1. `npm install` で警告 / 失敗する

```
npm warn deprecated whatwg-encoding@3.1.1: ...
2 moderate severity vulnerabilities
```

→ これらは依存パッケージ側の警告で、動作には影響なし。無視して OK。

### Q2. `npm run dev` でポートエラー

```
Error: listen EADDRINUSE: address already in use :::3001
```

→ 既に別プロセスがポート3001を使っている。以下のいずれかで対処:

```powershell
# 別ポート(3002)で起動
$env:PORT=3002; npm run dev

# またはポート3001 を使っているプロセスを kill
Get-NetTCPConnection -LocalPort 3001 | Select-Object -ExpandProperty OwningProcess | ForEach-Object { Stop-Process -Id $_ -Force }
```

### Q3. ブラウザで画面が真っ白 / エラー画面

1. dev サーバーの **ターミナル出力** にエラーが出ていないか確認
2. ブラウザの **DevTools コンソール** (F12) でエラーを確認
3. `npm run dev` を Ctrl+C で停止 → 再起動

### Q4. 「人脈営業ワークスペース」ではなく「採用管理ワークスペース」と表示される

→ **`tool/` ではなく `100_tool/workspace-ui-kit/`（テンプレート原本）を起動している可能性**。

`tool/` (実装モジュール) で起動しているか確認:
```powershell
cd "...\personal-network-sales\tool"
pwd
```

### Q5. 候補者リストが空 / エラー

→ `tool/data/candidates.json` が空または壊れている可能性。
```powershell
git -C "...\personal-network-sales" status
git -C "...\personal-network-sales" diff tool/data/candidates.json
```
で差分を確認 → 必要なら `git restore tool/data/candidates.json` で復元。
