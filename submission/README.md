# submission/ — 最終提出物

AI-Driven School 受講生ポータルへの提出に使う最終ファイルを置く場所です。

## 想定する中身

- 完成画面のスクリーンショット集 (`screenshots/`)
- 提出用ZIPファイル
- デモ動画
- 提出文書 (PDF / Markdown 出力)
- 中間発表用スライド

## 提出フローの想定

```
   docs/ で設計確定
        │
        ▼
   実装 (workspace-ui-kit 改造)
        │
        ▼
   スクリーンショット撮影 → assets/ に元画像
        │
        ▼
   提出用にまとめる → submission/ に配置
        │
        ▼
   受講生ポータルへアップロード
```

## ファイル命名

- 提出回数で連番: `submission_v1.zip`、`submission_v2.zip`
- スライドは: `presentation_2026-MM-DD.pdf`

## 注意

- 提出物に**個人情報・本物の営業データ**を含めない
- ダミーデータ・マスキング済みデータで撮影する
- ファイル容量に注意（受講生ポータル側の上限を確認）
